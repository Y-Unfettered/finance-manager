# 财务经理 APP

个人本地优先的资产、负债与记账管理工具。

## 当前状态

**已进入开发阶段。当前工程版本：`v0.0.7`；首页、资产总览和基础账户创建闭环已完成。**

首发边界：Android、单人、单账本、本地优先、人民币本位币。

代码仓库：[Y-Unfettered/finance-manager](https://github.com/Y-Unfettered/finance-manager)。每个完成版本都会同步更新版本记录、创建 Git 标签并推送到 GitHub。

## 发生冲突时的处理顺序

1. 当前版本是否开发，以 `开发路线图与MVP范围.md` 为准；
2. 功能业务含义和财务口径，以 PRD 为准；
3. 视觉尺寸和交互一致性，以 UI V3 规范为准；
4. 框架、数据库、组件库和原生实现，以技术选型方案为准；
5. PNG 只做视觉参考，不能覆盖明确的 Token 数值。

发现冲突时应修正文档，不允许开发者自行选择较方便的一种解释。

## MVP 闭环

```text
创建账本 → 账户与期初余额 → 导入历史账/开始记账
→ 资产、负债、应收正确联动 → 首页与流水核对
→ 完整备份 → 空库恢复验证
```

预算、周期账单、周报/月报、通知自动记账、无障碍和 OCR 均在 MVP 稳定后迭代。
