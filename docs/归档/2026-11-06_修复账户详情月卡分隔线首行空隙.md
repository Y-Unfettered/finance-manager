## 一、任务名称
修复账户详情月卡"分隔线与第一行之间 12px 空隙"——详情页裸 `section` 选择器 scoped 泄漏 bug。

## 二、需求沟通记录
- 提出时间：2026-11-05（用户看真机截图报告：11 月卡片第一行距上方分隔线空隙偏大，行间正常；要求第一行长按高亮矩形上边缘贴线）
- 我的理解：这不是组件间距调参，而是一个样式泄漏 bug。经 CDP 连真机实测（dpr3 / 视口 400）：
  - 真机上每张月卡根元素被强加了 `display: grid; gap: 12px`，header 分隔线与列表之间多出 12px（实测 `gap_line_to_row1Bg = 13px`，行间为 0）；
  - 来源是 `AccountDetailView.vue:835` 的 `section { display: grid; gap: var(--space-3) }`——本意是让多张月卡之间有 12px 间距，但 Vue scoped 下父组件的 data-v 属性会附加到子组件根元素上，月卡根恰好也是 `<section>`，被同一条规则命中；
  - 同页 hero 欠款卡（也是 section 根）同样中招，其子块间 12px 完全来自泄漏规则（`.hero` 自身无 gap，实测子块间距 [12, 28]，其中 16 为 credit-grid 自带 margin）。
  - 桌面复现不出，是因为此前手工复现 DOM 未包含详情页 scoped 规则。
- 建议方案（共 3 处改动，均在 AccountDetailView.vue）：
  1. 模板 `<section>` → `<section class="month-card-list">`（538 行）
  2. `section { display: grid; gap: var(--space-3); }` → `.month-card-list { display: grid; gap: var(--space-3); }`
  3. `.hero` 补 `gap: var(--space-3)`（保持欠款卡现有视觉，否则 label 与金额会贴上）
  修复后月卡根回到 BaseCard 默认 block 布局：分隔线与第一行之间 0px，第一行文字距线约 7.5px，与行间距（约 8.5px 含 1px 边线）一致，即用户认可的"下面几行"的紧度；长按高亮矩形上边缘贴线。
- 用户确认：☑ 已确认（2026-11-06，文档与方案 OK）
