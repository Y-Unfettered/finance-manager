## 一、任务名称
报表与统计页 UI 修缮：年份抽屉、KPI 信息层级、图表间距、单条目构成隐藏、账户月度表格。

## 二、需求沟通记录
- 提出时间：2026-11-06
- 我的理解（用户逐点反馈）：
  1. 年报模式的年份选择是 input 输入框，应改为与月报一致的抽屉滚动选择；
  2. 月报 KPI 卡（收入/支出/结余）全是灰色、层级不明 → 金额改大号黑字、标签灰小字、环比着色；
  3. 分类统计页 KPI（总收入/总支出/结余/笔数/日均/笔均）同样全灰 → 同上修法（复用共享样式）；
  4. 分类统计"月度趋势"柱状图间距过宽难看 → 调整柱宽/间距（MonthlyBarChart 全局）；
  5. 分类统计"分类构成"在无二级分类时只显示自己一条+看不懂的进度条 → 单条目时隐藏该模块；
  6. 账户统计"月度流入流出"柱状间距宽 → 调间距 + 补月度明细表格（月份/流入/流出）；
  7. 账户统计 KPI（总流入/总流出/净流入/转账还款）全灰 → 同 2/3 修法。
- 建议方案：KPI 信息层级统一为「标签灰 11px + 金额 16px/700 黑色（收入绿、支出红在 MoneyText tone 处已足够识别的位置保留）」——具体以"黑色为主、明确层级"实施；柱宽 7→20px。
- 用户确认：☐ 待确认（本文件）

## 三、目标
报表与统计页信息层级清晰（金额大而黑、标签灰小）、图表间距合理、无意义的单条目构成不再显示、年报年份用抽屉选择。

## 四、范围
**做什么：**
1. `MonthPickerSheet.vue`：新增 `yearOnly` 模式（仅年份列，确认返回年份）
2. `MonthlyReportView.vue`：年报年份选择改抽屉；KPI 卡金额改大号黑字、环比着色
3. `statistics-shared.css`：`.kpis` 金额 14px/600 → 16px/700/主色黑（tone 颜色不再依赖）；分类统计与账户统计共用生效
4. `MonthlyBarChart.vue`：barMaxWidth 7 → 20（分类统计/账户统计的月度柱状间距收紧）
5. `CategoryStatisticsView.vue`：distribution ≤1 条时隐藏"分类构成"卡
6. `AccountStatisticsView.vue`：月度流入流出卡下方补月度明细表格（月份/流入/流出/净额）
**明确不做什么：**
- 不改数据接口/统计逻辑
- 不做图表大改版（堆叠图等仍留后续）
- 不动月报五板块/年报四板块的既有结构
