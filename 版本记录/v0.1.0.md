# 财务经理 APP v0.1.0 版本记录

> 日期：2026-08-03
> 状态：已完成
> 对应里程碑：Sprint 4 完成，MVP 发布版

## 1. 本版本目标

完成 Sprint 4 剩余项（应用锁、隐私遮挡、migration 前自动备份），达到 MVP 发布门槛。用户可以把已有账导进来，继续准确记账，随时看到钱在哪里、欠多少、别人欠自己多少，并且数据能够完整备份和恢复，同时应用本身具备基本的隐私保护。

## 2. 新增内容

### 应用锁（PIN 码）

- 在"我的 → 安全 → 应用锁"中设置 4 位数字 PIN 码。
- 启用后每次打开应用需输入 PIN 解锁，切到后台再回来也需重新解锁。
- PIN 使用 SHA-256 + 16 字节随机盐哈希存储，不保存明文。
- 支持：设置 PIN、修改 PIN（需验证旧 PIN）、关闭应用锁、临时禁用。
- 设置项存储在数据库 `app_settings` 表中，随备份/恢复一起走。

### 最近任务隐私遮挡

- 监听 Capacitor App 的 `appStateChange` 事件。
- 应用切到后台时显示遮挡层（"财务经理"文字），防止系统任务列表预览泄露账目。
- 回到前台时隐藏遮挡层；如已启用应用锁则显示解锁页。

### migration 前自动备份

- 数据库 schema 升级前自动检测 pending migration。
- 生成完整 JSON 备份（含 SHA-256 校验值）到 Documents 目录。
- migration 失败时提示用户备份路径，可通过"备份与恢复"页恢复数据。
- 备份失败不阻塞 migration。

## 7. 已知问题与限制

- 崩溃、断电、低存储极端场景测试待真机验证。

- migration 备份不包含 `app_settings` 表（v7 新增），但应用锁设置可重新创建。
