## 1. 本版本目标
把 `0.5.0` 之后累积完成的功能（自动记账链路完善、分类体系整改、报表统计、到期提醒、开发规范等）统一标记为发布版本 `2.1.0`，并建立"任务驱动"版本策略（第一位=发布、中间位=功能、最后位=补丁，见项目 AGENTS.md）。

## 2. 新增内容
- **自动记账**：支付宝还花呗捕获模板与还款接线；读屏工具与链路修复（批一）；记账页分类就地展开与拖拽排序。
- **到期提醒**：按月循环（月末 clamp）、首页开 APP 弹窗（今日不再提醒）、信用卡账期自动还款提醒、到期提醒体验修复（三处）。
- **报表统计**：月报年报一期（聚合报告）、报表统计 UI 修缮。
- **分类体系与体验一致性整改**（21 批次）。
- **设置·账本与数据**：新增"模板与周期交易""到期提醒"两个入口。
- **工具类**：开发规范 skill（dev-workflow）+ 个人经验库 + AI 署名规范（独立于 APP 功能，供多工具协作）。

## 3. 修改与调整
- 账户详情：月卡去账本标签、日期拼接备注、分隔线首行空隙修复；导入批次页卡片间距；AppDateInput normalizeDate 空段防御；统计选中日期后值框溢出修复；卡片边距整理（匹配规则页面）。

## 4. 修复内容
- 自动记账修复批一（读屏工具与链路修复）；日志统一（原生控件改造）；分类体系相关 UI 一致性修复。

## 5. 数据库与兼容性
- 新增 migration：`020_reminder_recurrence`（提醒循环）、`021_reminder_managed_by`；同步 `backup-repository` 的 `TABLE_SCHEMAS`。
- 备份兼容：旧备份恢复含新列，与历史加列行为一致；`schema_migrations` 不参与恢复（沿用约定）。
