# 财务经理 APP v0.2.1 版本记录

> 日期：2026-08-04
> 状态：已完成
> 对应里程碑：基础交互补全 Sprint

## 1. 本版本目标

用户反馈 v0.2.0 虽然新增了四大效率模块，但基础交互仍缺失严重：首页三横菜单跳测试页、账期无法切换、预算卡片无反应、流水无法编辑、资产页无法滚动、借入借出数据不可见、账户流水详情无法点击。本版本集中补齐以上基础体验问题，让日常高频操作先可用。

## 2. 新增内容

### 侧栏导航 SideDrawer

- 新建 `src/components/SideDrawer.vue`。
- 采用 Vant Popup 左侧抽屉，宽度 72%，头部带头像、账本名称（日常账本）、共 1 个账本副标题。
- 导航条目 9 项，完全对齐用户列出的需求：
  - 我的账本 → 跳转 home
  - 报销管理 → 规划中
  - 搜索 → 跳转 search
  - 账单 → 规划中
  - 分期 → 规划中
  - 周期存钱计划 → 规划中
  - 意见与反馈 → 规划中
  - 关于 → 规划中
  - 设置 → 跳转 profile
- 底部 footer 显示 v0.2.1 版本号。

### 交易详情弹层 TransactionDetailSheet

- 新建 `src/components/TransactionDetailSheet.vue`，复用 AppBottomSheet。
- 展示：交易类型标签、金额、撤销状态标记。
- 详情页提供复制、修改和删除入口。
- 修改会跳转快速记账页，可调整金额、账户、分类、商户和备注；发生时间保持原记录时间。
- 删除采用文字确认和随机四位数字校验，确认后将原交易标记为撤销。
- 已撤销交易不能再次编辑或删除。

## 3. 修改与调整

### HomeView 首页

- 接入 SideDrawer：左上角 Menu 按钮 → showDrawer = true。
- AppTopBar 开启 period-switchable，点击标题触发 showPeriod BottomSheet。
- 账期选择器：ChevronLeft / ChevronRight 切月，月份切换自动重新调用 loadHome；「回到本月」回到当前月份并关闭弹层。
- 右上角 ListFilter 按钮 → goSearch 跳转 `/search`。
- 预算卡片：
  - 用 BudgetService.getBudgetForPeriod 获取真实预算（currentMonthPeriodKey + ledgerId）。
  - 计算 total / spent / remaining / percent / overspent，进度条超支时变红。
  - 卡片点击 → goBudget 跳转 `/budget`。
  - 未设置预算时提示「未设置预算，点击设置」。
- 流水卡片：DailyLedgerCard 绑定 @select → openTransaction，弹出 TransactionDetailSheet；更新后刷新 loadHome。
- watch(currentMonth) 自动重载首页数据。

### DailyLedgerCard

- 每笔流水从 `<div>` 改为 `<button>`，@click emit('select', item)，点击态背景色。

### AccountsView 资产页

- 新增 borrow-card BaseCard 分区，左半「总借入」跳转 payables（ArrowDownToLine 图标），右半「总借出」跳转 receivables（ArrowUpFromLine 图标），中间竖线分割。数据来自 overview.borrowedMinor / overview.lentMinor。
- section-card__body 移除原先的 max-height 68dvh 限制；assets-page 自带 padding-bottom 保证底部能滚出安全区。
- 每一条 section-card__row 改为 button，点击 → openAccount(account) 跳转 account-detail 详情页。

### AccountDetailView 账户详情

- 账户流水区（activity-section）每一行从 `<div>` 改为 `<button>`，key = `${item.id}-${item.transactionId}` 防止重复。
- openActivity(item) → activeTxId = item.transactionId → showTxDetail = true，弹出 TransactionDetailSheet，更新后重新 load。
- activity-row :disabled 判断取消（所有行都对应了 transactionId）。

### TransactionRepository 账户流水查询

- `AccountActivityRecord` 接口新增 `transactionId: string` 字段。
- `listByAccount` SQL 改为：
  - `SELECT entries.id, transactions.id AS transactionId, ...`
  - 原 transactions.id 改为 entries.id（作为账户分录级 id），保留 transactionId 关联原交易。
- 这是为了让 AccountDetailView 每一条流水都能打开对应的交易详情。

### SideDrawer defineEmits 修复

- 之前 SideDrawer 写了两次 defineEmits，移到顶部 `const emit = defineEmits<...>()`，移除重复声明。

### 版本号

- `app/package.json`：0.2.0 → **0.2.1**
- `app/android/app/build.gradle`：versionCode 20 → **21**，versionName 0.2.0 → **0.2.1**
- SideDrawer footer 同步 v0.2.1。

## 7. 已知问题与限制

- 未实现的侧栏项（报销管理、账单、分期、周期存钱计划、意见与反馈、关于）统一打「规划中」标签，点击无跳转，不影响已开放功能。
- 预算卡目前仅显示总额度 + 总进度，分类明细入口放在 BudgetView 详情页，未在首页直接展开。
- 周期交易仍不自动入账、提醒仍不发系统通知（保持 0.2.0 限制，0.3.0 一起解决）。
- 交易完整编辑当前通过“撤销旧交易并创建新交易”实现，因此编辑后会产生新的交易 ID，原记录保留为已撤销状态。
- 撤销操作只把交易 status 改成 void，不可逆；如误撤销需重新记一笔，与之前 finance-service.voidTransaction 设计保持一致。

- **通知监听自动记账**：监听 Android NotificationListenerService，捕获支付宝 / 微信 / 银行推送 → 解析金额 / 商户 / 时间 → 生成草稿交易 → 用户确认或自动入账。
