# 财务经理 APP v0.0.9 版本记录

> 日期：2026-08-03
>
> 状态：开发完成，待最终发布核验
>
> 对应里程碑：借入款闭环、多模式记账与账户生命周期

## 1. 本版本目标

延续 v0.0.8 的借出款能力，正式补齐“我欠别人钱”的借入款与归还借款闭环；同时让快速记账从单一支出扩展为支出/收入/转账三种模式，并为账户详情补充重命名与归档操作，让账户生命周期可被用户主动管理。

## 2. 新增内容

### 多模式快速记账

- 原 `NewExpenseView` 升级为支出 / 收入 / 转账三模式合一的快速记账页。
- 顶部 Tab 切换模式，页面标题、字段集合和校验规则随模式变化。
- 收入模式调用 `FinanceService.createIncome`，写入收入分类与收款账户。
- 转账模式调用 `FinanceService.createTransfer`，仅生成转出账户与转入账户之间的资金移动分录，不计入收支统计。
- 转账模式可选目标账户自动排除当前转出账户，避免自转。

### 借入款管理

- 新增 `PayablesView`，对称 `ReceivablesView`：顶部摘要展示待归还金额、待还笔数与已结清笔数。
- 新增借入款时填写债权人/事项、金额、转入账户、借入时间、约定还款日和备注。
- 借入操作创建独立 `other_liability` 账户并生成 `borrowing` 分录：转入账户增加、应付账户增加。
- 支持登记部分归还；生成 `repay_borrowing` 分录：应付账户减少、还款账户减少。
- 剩余待还金额归零后自动将记录标记为已结清。
- 归还金额超过待还金额时拒绝保存。
- 资产页“借入款”入口与原“借出款”入口对称展示，点击进入借入款列表。

### 账户重命名与归档

- `AccountDetailView` 新增“重命名”、“归档账户”/“取消归档”操作入口，与“调整余额”并排展示。
- 重命名通过专用弹层修改账户名称，更新 `updated_at`。
- 归档要求账户当前余额为 0；非零余额会拒绝保存并提示先调整或转账。
- 归档后账户卡片显示“已归档”标签并降低不透明度；取消归档可恢复。
- `AccountRepository` 提供 `rename`、`archive`、`unarchive` 原子操作；`FinanceService` 在调用前校验账本归属和余额约束。

### 数据库与兼容性

- Schema 升级到 v3，新增 `payables` 表，保存债权人、原借入金额、约定还款日、备注和状态。
- 新迁移只追加表和索引，不重建 v1/v2 账户、流水或余额视图。
- 增加 v1 → v3 与 v2 → v3 数据库升级后原账本仍存在的自动化测试。

## 3. 财务口径

- 借入款是负债账户与资金账户之间的同步增加，不是收入。
- 归还借款是负债账户与资金账户之间的同步减少，不是支出。
- 总借入等于所有应付账户当前余额之和，不等于历史累计借入金额。
- 已部分归还的记录显示剩余待还金额，同时保留原借入金额。
- 账户转账只在不同资金账户之间移动，不计入月收入或月支出。
- 账户重命名只更新展示名称，不影响分录历史。
- 账户归档只标记状态，不删除账户或历史流水；归档后该账户不再计入资产/负债聚合。

## 5. 已知限制

- 借入款暂不支持修改债权人、到期日或删除；可通过归还结清。
- 借出款仍不支持编辑到期日和备注（沿用 v0.0.8 限制）。
- 账户归档不删除账户；如需彻底删除需先调整余额为 0 后通过未来版本的“删除”入口处理。
- 快速记账页仍不支持编辑或撤销已保存交易；后续版本补齐。
- 资产趋势仍是当前资产负债比例，历史净资产折线需要后续快照数据。
