# 财务经理 APP v0.3.0 版本记录

> 日期：2026-08-08
>
> 状态：Web 与 Android 构建完成，目标手机安装及启动冒烟验证通过
>
> 对应里程碑：新版 PRD 整体可用性重构

## 1. 本版本目标

以 `财务经理APP_PRD.md` 为基线，参考 `UI参考图` 中的钱迹页面，集中重构信息架构、日常记账、预算、分类、账户资产、统计、多账本和设置，使主要功能形成可连续操作的闭环。

## 2. 主要实现

### 导航、首页、账单与搜索

- 侧边栏仅保留我的账本、搜索、账单和设置，底部导航收口为首页、记账和资产。
- 首页保留月收支背景卡，新增预算概览与可配置的本周、最近 7 日、最近 15 日收支汇总。
- 账单页支持月份、类型、账户、分类筛选及列表/日历视图；日历可切换收支、结余、收入和支出。
- 搜索覆盖关键词、日期、账户、分类、交易类型和金额区间，结果按日期分组并可进入详情。

### 预算与分类

- 预算实现三种业务模式，以及总预算与分类预算相等/大于时的不同计入口径。
- 新月份自动复制最近一期预算配置；仅分类预算时自动汇总为总预算。
- 一级分类预算汇总其二级分类支出，关联退款回到原交易月份和原分类冲减。
- 分类管理支持收支分类、两级结构、图标颜色、排序、归档恢复和分类统计入口。

### 记账与退款

- 快速记账主入口仅保留支出、收入、转账；负债账户支出自动记为信用消费。
- 还款从信用账户详情发起；退款只能从原交易详情发起，强制关联原交易并校验累计退款上限。
- 原交易存在退款时禁止直接修改或删除，避免破坏退款链路。
- 交易完整编辑在同一数据库事务内撤销旧交易并写入新交易，失败时保留旧交易。
- 支持最多 3 张、单张不超过 3 MB 的本地图片凭证，详情可查看，并纳入备份恢复。

### 资产、账户与统计

- 资产页展示净资产、总资产、总负债、借入借出、账户分组与资产趋势。
- 资产快捷按钮支持添加账户、账户分组显隐管理和显示已归档账户。
- 账户补齐类型、名称、机构、品牌图标、主题色、是否计入资产统计、是否在记账时显示等资料。
- 信用账户展示欠款、额度、可用额度、出账日、还款日及按账期归集的消费、退款和还款。
- 新增分类统计、账户统计、资产统计，支持常用时间范围、自定义区间、趋势、分布和明细钻取。

### 多账本、设置与数据

- 多账本支持创建、切换、改名、归档和恢复，并防止归档最后一个可用账本。
- 设置页集中管理首页汇总、金额隐藏、默认账户、记住上次账户、浅色/深色/跟随系统主题及数据工具。
- 数据库升级至 Schema v9，新增预算策略、信用资料、账户/分类偏好、退款关联、账本偏好和交易附件等数据结构。
- 旧数据库自动迁移；旧备份缺少新表时按空表恢复，保持向后兼容。

## 4. 当前边界

- 账户分组管理提供固定业务分组的显示/隐藏，暂不支持用户新建任意分组或拖拽排序。
- 分类排序提供明确的上移/下移操作，移动端长按拖拽将在真机交互验收后评估。
- 图片凭证保存在本地 SQLite，适合少量凭证；大量长期图片后续可迁移到文件系统并在数据库保存引用。
- 已完成 Debug 安装与启动冒烟验证，但尚未完成全部页面的人工交互和极端场景验收，因此仍不视为正式发布包。
