# 财务经理 APP v0.0.1 版本记录

> 日期：2026-08-03  
> 状态：已完成  
> 对应里程碑：Sprint 0 第一部分

## 1. 本版本目标

建立能够持续开发、测试和生成 Android 工程的 Vue 3 基线，并把 UI V3 规范从文档落实为第一批可复用代码组件。

本版本不是业务 MVP，不写入真实财务数据。

## 2. 新增内容

### 工程

- 创建 `app` 前端工程：Vue 3、TypeScript、Vite。
- 接入 Vue Router 与 Pinia。
- 接入 Capacitor 8 并生成 Android 原生工程。
- 临时 Android application ID：`app.financemanager.local`。
- Web viewport 支持 `viewport-fit=cover`，为 HyperOS edge-to-edge 做准备。

### 组件与样式

- 建立 `tokens.css`：尺寸、间距、圆角、颜色、字阶、动画和 Vant 主题变量。
- 建立全局基础样式和 `prefers-reduced-motion` 降低动画支持。
- 新增 `AppIconButton`。
- 新增严格三栏结构的 `AppTopBar`。
- 新增 `BaseCard`。
- 新增整数分金额展示组件 `MoneyText`。
- 新增 `AccountAvatar`。
- 新增基于 Vant Popup 的 `AppBottomSheet`。
- 新增开发组件基线页，用于验证组件组合，不作为正式业务首页。

### 工程质量

- 配置 TypeScript strict 与额外的索引安全检查。
- 配置 Vitest、Vue Test Utils 和 jsdom。
- 为 `MoneyText` 增加人民币、收入正号和支出负号测试。
- 配置 ESLint、Prettier 和忽略目录。
- 增加生产构建、测试、Lint、格式检查和 Capacitor 同步脚本。

### 版本管理

- 建立根目录 `CHANGELOG.md`。
- 建立版本记录制度、模板和独立版本文档。
- 前端版本设为 `0.0.1`。
- Android `versionCode` 为 `1`，`versionName` 为 `0.0.1`。

## 3. 修改与调整

- Vant 不再全量引入样式，`AppBottomSheet` 只引入 Popup 所需样式。
- TypeScript 路径别名采用 TypeScript 6 兼容写法。
- 所有基础组件只引用 UI Token，不在业务页面散落随机色值和尺寸。

## 4. 修复内容

- 修复 TypeScript 无法解析 `@/` 别名的问题。
- 修复 Vite 配置中 Vitest 类型无法识别的问题。
- 修复 ESLint 将浏览器事件类型识别为未定义变量的问题。

## 5. 数据库与兼容性

- 本版本尚未创建财务数据库。
- 无 migration。
- 无历史数据兼容问题。

## 7. 已知问题与限制

- application ID 是开发阶段临时值，首个长期安装版本前需要确认是否保留。
- 组件基线页只有设计系统示例，没有账本、账户和交易数据。
- SQLite、账务分录和数据库 migration 尚未开始。
- 账期与筛选弹层当前只展示占位内容。
- 尚未在小米 17 Pro Max 真机上安装验收。
- 标准 Gradle Wrapper 8.14.3 因当前网络无法连接分发站未完成下载；本次使用与 Android Gradle Plugin 8.13 匹配的本机 Gradle 8.13 缓存成功构建。

## 8. 下一版本计划

### 版本号

`v0.0.2`

### 核心目标

建立账务数据地基，并用自动化测试证明第一组业务交易能够正确生成分录。

### 计划内容

- 接入 Capacitor Community SQLite。
- 建立 `ledger`、`account`、`category`、`transaction`、`entry` 的 schema v1。
- 建立 migration runner 和数据库版本表。
- 建立金额、账户类型、交易类型和分录方向等 TypeScript 领域类型。
- 完成支出、收入、转账和信用消费的分录规则。
- 为上述规则建立固定测试账套和余额断言。

### 明确不做

- 不制作正式首页。
- 不实现 CSV/钱迹导入。
- 不实现自动记账。
- 不实现预算和报表。
