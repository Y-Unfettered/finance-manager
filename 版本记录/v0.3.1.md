# 财务经理 APP v0.3.1 版本记录

> 日期：2026-08-09
>
> 状态：已完成并安装到目标手机，三方向手势验收通过
>
> 对应问题：首页顶部错位、横向切页生硬、缺少右滑侧栏

## 1. 问题根因

- 通用顶部栏右侧网格只有 56px，却放入三个 48px 按钮，CSS Grid 因空间不足自动排成三行，并撑开菜单和账期所在行。
- Swipe 完成切页后会更新路由；路由监听又调用一次 `swipeTo(..., { immediate: true })`，导致原本的收尾动画被立即定位截断。
- 首页处于第一张 Swipe 时，组件会忽略继续向右的边界手势，原实现没有把该手势转交给侧边栏。

## 2. 修复内容

- 顶部栏使用 `1fr / auto / 1fr` 三栏布局，左右槽分别贴边，中间标题保持物理居中。
- 右侧槽固定横向、不换行，恢复参考图中的日历、统计、资产三图标排列。
- 账期显示改为 `YYYY-MM`，预算快捷入口改回三个点。
- 路由目标已经等于当前 Swipe 页时不再重复定位；外部导航切页保留动画。
- 切页使用 280ms `cubic-bezier(0.22, 1, 0.36, 1)` 强减速曲线。
- 首页识别水平向右手势并打开侧边栏；垂直滚动不会误触发。
- Vant Popup 与基础动画统一使用项目 Motion Token。
