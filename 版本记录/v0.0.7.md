## 1. 本版本目标

按照用户提供的钱迹资产页、添加资产分类和银行选择参考图，重做现有简易账户列表，形成“首页左滑 → 资产总览 → 添加分类 → 选择银行 → 创建账户”的完整操作路径。

## 2. 新增内容

### 首页与资产页联动

- 首页和资产页由 Vant Swipe 承载，采用成熟组件处理横向方向锁定、拖动距离和 220ms 过渡。
- 首页向左滑进入资产页，资产页向右滑返回首页。
- 滑动后同步更新路由为 `/` 或 `/accounts`，底部导航激活状态同步变化。
- 点击底部“首页/资产”也会驱动同一个 Swipe 切换，不维护两套页面状态。

### 资产总览

- 顶部居中显示净资产，可一键隐藏全部金额。
- 下方双列显示总资产和总负债。
- 资产趋势卡显示资产/负债账户数量、负债率和比例轨道。
- 借入借出卡显示其他负债账户合计和应收款账户合计。
- 分组汇总显示信用卡、资金、充值、投资；存在应收或其他负债时自动增加对应行。
- 点击分组可查看该类全部账户、机构和实时余额。
- 资产数据全部由 SQLite 实时账户余额聚合，不使用演示金额。

### 添加资产入口

- 右下角新增 56px 主色圆形添加按钮，位于底部导航上方。
- 点击后打开“选择账户分类”底部弹层。
- 账户目录分为资金账户、信用卡账户、充值账户、投资账户。
- 资金账户覆盖现金、微信、微信零钱通、支付宝、余额宝、余利宝、小荷包、云闪付、银行卡、公积金、医保、数字人民币、华为钱包、多多钱包、PayPal 和其他。
- 信用账户覆盖信用卡、花呗、借呗、京东白条、美团月付、抖音月付、微信分付和其他信用。
- 充值账户覆盖通用充值、餐饮、美容美发、蛋糕、健身和交通卡。
- 投资账户覆盖股票、基金、债券、银行理财、黄金和数字资产。

### 品牌与银行目录

- 新增统一 `AccountBrandIcon`：32/40/48px 三种尺寸、圆形品牌色背景、白色粗体字形。
- 没有可靠授权 SVG 时使用可识别的中文字或字母，不抓取未知来源图片。
- 银行卡和信用卡进入二级银行选择弹层。
- 银行选择支持搜索，内置中国、招商、工商、农业、建设、交通、浦发、广发、邮储、农村信用社、平安、中信、兴业、光大、民生、华夏、北京和成都银行。
- 选择银行后自动填充账户名称和机构，用户仍可修改。

### 业务与测试

- 账户创建扩展为支持全部 `AccountType`。
- 新增资产、负债、净资产、负债率、借入借出和分组汇总纯函数。
- 新增资产汇总测试和投资/信用卡账户方向测试。
- 底部弹层 Teleport 到 `body`，保证其不被 Swipe 的横向轨道裁切。

## 3. 数据口径

- 总资产：全部正常余额方向为借方的账户余额之和。
- 总负债：全部正常余额方向为贷方的账户余额之和。
- 净资产：总资产减总负债。
- 总借入：`other_liability` 账户余额之和。
- 总借出：`receivable` 账户余额之和。
- 负债率：总负债 ÷ 总资产；总资产不大于 0 时显示 0%。
- 信用卡分组包含信用卡和消费信贷；资金包含现金、银行、平台和受限资产。

## 5. 已知限制

- 新建账户初始余额暂为 ¥0.00，界面已明确提示；期初余额将在 v0.0.8 接入。
- 资产趋势当前展示资产负债比例，不是历史净资产折线；历史快照将在产生足够数据后实现。
- 借入借出统计已接入应收和其他负债账户，但对应的借出款/收回款表单尚未开放。
- 账户分组明细暂不支持编辑、归档和对账。
- 品牌圆标为统一风格的本地字形标识，不代表品牌方官方授权 Logo。
